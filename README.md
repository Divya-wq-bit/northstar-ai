# northstar-ai
An adaptive AI personal mentor that creates a personalized roadmap for each user based on their goals, current state, lifestyle, habits and working style. It continuously understand real-life events, adapts priorities and replans the journey to keep the user moving towards their North Star Goal.

## Core Idea
You choose the destination.

NorthStar AI figures out the journey.

The system understands real-life events, prioritizes what matters now, replans affected tasks and keeps the user moving toward their long-term Goal.

## Example
**NorthStar AI Goal:** Become placement-ready by January 2027.

**Life happens:** "I have DBMS exam next Thursday and I've studied nothing."

NorthStar AI temporarily prioritizes DBMS, adjusts the placement workload, preserves the original roadmap , and redistributes postponed work after the exam.
